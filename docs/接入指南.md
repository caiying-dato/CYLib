# CYLib 接入指南（给其他模组的开发会话）

CYLib 是 CY 系列模组的**配置平台**：它在游戏主界面（模式 / 时间线 / 百科 那排按钮处）提供
「模组配置」入口，各模组只要**注册一个配置页**，就能得到统一的配置界面、持久化存储与
默认值重置能力，不需要自己写 UI、自己管存档。

本文是给**负责具体模组的会话**看的：照着做即可完成接入。CYLib 平台本身已经搭好，
不需要你改 CYLib 的任何代码。

---

## 0. 一分钟上手（最小可用）

在你的模组里加两样东西：

**① 入口清单 `MyMod.json` 声明依赖**（保证 CYLib 先于你的模组加载）：

```json
"dependencies": [{ "id": "CYLib", "min_version": "v0.1.0" }]
```

**② 工程引用 CYLib.dll，并在初始化里注册配置页：**

```csharp
using CYLib.Config;

// 在你的 [ModInitializer] 方法里：
CYLibConfig.Register(
    new ConfigPageBuilder("MyMod", "我的模组")
        .Section("常规", s => s
            .Toggle("enable_x", "启用 X", defaultValue: true,
                    onChanged: v => MyMod.EnableX = v,
                    description: "打开后……")
            .IntSlider("power", "强度", min: 1, max: 10, defaultValue: 3,
                       onChanged: v => MyMod.Power = v))
        .Build());
```

完成。启动游戏 → 主界面点「模组配置」→ 左栏出现"我的模组"，右栏就是你声明的设置项。
值会自动持久化，下次启动自动读回。

读值（随时）：

```csharp
bool on  = CYLibConfig.GetBool("MyMod", "enable_x");
int pow  = CYLibConfig.GetInt("MyMod", "power", 3);
```

## 1. 工程接入（csproj）

CYLib.dll 编译产物在 `C:\DeepSeek Harness\CYLib\dist\CYLib\CYLib.dll`（`deploy.ps1` 每次
构建都会同步一份）。在你的 csproj 里加引用，**`Private=false`（不要把 CYLib.dll 复制进你的
模组目录）**：

```xml
<ItemGroup>
  <!-- CYLib：配置平台。Private=false 很重要——CYLib.dll 由 mods/CYLib/ 提供，
       复制一份到你的模组目录会造成同一程序集被加载两次、类型身份分裂。 -->
  <Reference Include="CYLib">
    <HintPath>..\CYLib\dist\CYLib\CYLib.dll</HintPath>
    <Private>false</Private>
  </Reference>
</ItemGroup>
```

（`HintPath` 按你的工程实际相对位置调整；BetterAscension 与 CYLib 是同级目录，用
`..\CYLib\dist\CYLib\CYLib.dll` 即可。）

运行时解析：游戏按依赖顺序加载模组，CYLib 的程序集会先加载进默认上下文，你的模组
引用 `CYLib.Config.*` 时直接绑定到它。**不要**用 `Assembly.Load` 之类的手段自己找。

## 2. API 参考（命名空间 `CYLib.Config`）

### 2.1 注册

```csharp
// 方式一：builder 链式（推荐）
ConfigPage page = CYLibConfig.NewPage("MyMod", "我的模组")
    .Describe("页头说明文字")        // 可选
    .Order(10)                       // 可选，左栏排序权重，小的在前
    .Section("小节标题", s => s
        /* 设置项… */)
    .Build();
CYLibConfig.Register(page);

// 方式二：一步到位
CYLibConfig.Register("MyMod", "我的模组", page => page
    .Section("常规", s => s.Toggle(...)));
```

- `modId` 必须等于你模组清单里的 `id`（它同时是配置文件名）。
- **任意时机注册都可以**：配置界面每次打开都会重新读注册表，晚注册也会出现在列表里。
- 同 `modId` 重复注册 = 替换旧页（已保存的值保留）。

### 2.2 设置项类型（`ConfigSectionBuilder` 的链式方法）

| 方法 | 类型 | 说明 |
| --- | --- | --- |
| `Toggle(id, label, defaultValue, onChanged, description)` | bool | 开关（绿=开/红=关 状态指示） |
| `IntSlider(id, label, min, max, defaultValue, step, onChanged, description, format)` | int | 整数滑条；`format` 如 `"{0:0} px"` |
| `IntInput(id, label, min, max, defaultValue, onChanged, description, controlWidth, fontSize)` | int | 数字输入框；提交时解析，越界按 min/max 夹取 |
| `FloatSlider(id, label, min, max, defaultValue, step, onChanged, description, format)` | double | 浮点滑条 |
| `FloatInput(id, label, min, max, defaultValue, onChanged, description, controlWidth, fontSize)` | double | 小数输入框；提交时解析，越界夹取 |
| `Text(id, label, defaultValue, onChanged, description, maxLength, placeholder, validator, onRejected)` | string | 单行文本；`validator` 拒绝时红框提示并回调 `onRejected` |
| `Choice(id, label, defaultValue, onChanged, description, (值, 文案), …)` | string | 下拉选项 |
| `Hotkey(id, label, defaultValue, onChanged, description)` | string | 热键绑定（按键捕获、支持 Ctrl/Shift/Alt+键；存 `"Ctrl+F8"` 这样的字符串；空=未绑定） |
| `Button(id, label, onClick, description, color)` | — | 动作按钮（不存值） |
| `Info(text)` | — | 纯展示文字（**动态**：传 `() => 文本` 时随配置变动自动刷新） |
| `Info(text, fontSize, color)` | — | 纯展示文字（自定义字号/颜色） |
| `InfoTitle(text)` | — | 醒目提示（金色大字；支持 `() => 文本` 动态版） |
| `Header(title, description)` | — | 小节内的分组标题（惰性文本同样自动刷新） |

小节本身可折叠：`section.Collapsed()` 让它初始收起。

> 所有 `label` / `description` / 标题类参数都是 `LazyText`：可以传字符串字面量，
> 也可以传 `new LazyText(() => 文本)` 的解析器（推荐，见 §3）。
>
> **尺寸可调（v0.1.3）**：每个设置项方法末尾都有 `controlWidth` / `fontSize` 两个可选参数
> （也可在直接构造的定义对象上设 `ControlWidth` / `FontSize` 属性）。
> **先用平台默认**（宽度 320、字号 20），觉得不合适再由各模组按项微调，
> 例如数字框嫌宽：`IntInput(..., controlWidth: 160)`。

### 2.3 进阶：直接构造定义对象

需要 `Hidden`（存盘但不出现在 UI）、`RequiresRestart`（标注"需要重启生效"）、
`VisibleIf` / `EnabledIf`（条件显隐/置灰）时，直接 new 定义对象再 `.Add(...)`：

```csharp
.Section("高级", s => s
    .Add(new BoolSetting("debug_mode", "调试模式") { Hidden = true })            // 不显示但存盘
    .Add(new IntSetting("threads", "线程数") { Min = 1, Max = 16, DefaultValueRaw = 4,
          RequiresRestart = true })
    .Add(new BoolSetting("extra", "额外选项") { VisibleIf = () => CYLibConfig.GetBool("MyMod", "enable_x") }))
```

设置项定义类（`CYLib.Config`）：
`BoolSetting` / `IntSetting` / `FloatSetting` / `TextSetting` / `ChoiceSetting` / `HotkeySetting` / `ButtonSetting`，
公共属性：`Id`、`Label`、`Description`、`Hidden`、`RequiresRestart`、`VisibleIf`、`EnabledIf`、
`OnChanged`（值变化回调）、`DefaultValue`、`ControlWidth`、`FontSize`。
`IntSetting.Style` / `FloatSetting.Style = NumberStyle.Input` 可让数字项渲染成输入框
（等价于 `IntInput(...)` / `FloatInput(...)`）。数字输入**严格解析**：不规范的输入
（如全角句号 `1。5`）不会被自动纠正，而是红框提示并回退旧值。

### 2.4 取值与写值

```csharp
CYLibConfig.GetBool(modId, key, fallback);
CYLibConfig.GetInt(modId, key, fallback);
CYLibConfig.GetFloat(modId, key, fallback);
CYLibConfig.GetText(modId, key, fallback);
CYLibConfig.Get<T>(modId, key, fallback);

CYLibConfig.Set(modId, key, value);      // 程序化写值：触发回调 + 立即落盘
CYLibConfig.RestoreDefaults(modId);      // 整页恢复默认（UI 里的"重置为默认"按钮干的就是这个）
CYLibConfig.Save();                      // 手动落盘（一般用不到：UI 改动 0.5s 防抖自动存、退出时强制存）
CYLibConfig.GetFilePath(modId);          // 配置文件完整路径（调试/自检用）
```

### 2.5 变更通知

```csharp
CYLibConfig.ValueChanged += change =>
{
    // change.ModId / change.Key / change.OldValue / change.NewValue / change.Source
    if (change.ModId == "MyMod" && change.Key == "enable_x")
        ApplyX(change.NewValue is bool b && b);
};
```

`OnChanged` 回调（在设置项定义上）与 `ValueChanged` 事件都会触发；
`change.Source` 区分 `ConfigChangeSource.Ui`（玩家在界面里改）与 `Api`（代码 Set）。

### 2.6 v0.1.2 新增能力详解

**动态信息行**——`Info(Func<string>)` / `InfoTitle(Func<string>)` 传入的解析器在**每次配置
变动后自动重新求值**（UI 建页时也会求值一次），可直接做"随值变化的预览/提示"：

```csharp
.Info(() => $"当前增幅：{ComputePreview()}")
.InfoTitle(() => $"预计伤害：{Estimate()}")
```

不需要自己订阅 `ValueChanged` 刷新，更不要去扫场景树改 Label。

**热键行**——`.Hotkey("toggle_key", "总开关热键", "F8")`：点击按钮进入捕获态，按下
组合键即绑定（`"Ctrl+Shift+K"`），Esc 取消、Backspace 清除、同页撞键红框提示。
**按键派发由模组自己做**（CYLib 只管录入/存储/展示），读值：`CYLibConfig.GetText("MyMod", "toggle_key")`。

**校验拒绝反馈**——`Text(...)` 的 `validator` 拒绝时输入框红框提示并回读旧值，
同时回调 `onRejected(被拒文本)`（可弹自己的提示）；重新输入即消除红框。
`IntInput` 解析失败同样红框回退。

**类型宽容读取**——`GetInt`/`GetFloat`/`GetBool` 能读出"字符串形式"的数字/布尔
（比如早期用 `TextSetting` 变通存的 `"25"`），**旧值无需迁移即可读回**；
下次写入时自动规整为正确类型。

**旧配置迁移**——从自研 cfg/旧格式迁到 CYLib，推荐"首次注册时灌一次"：

```csharp
if (!File.Exists(CYLibConfig.GetFilePath("MyMod")) && File.Exists(oldCfgPath))
{
    foreach (var (key, value) in ParseOldCfg(oldCfgPath))
        CYLibConfig.Set("MyMod", key, value);   // 写入即落盘；之后 CYLib 全权接管
}
```

**动态行文案（v0.1.4）**——设置项自己的 `Label` / `Description` 传**解析器**时，
与动态 Info 一样随配置变动自动重新求值（传字面量则照旧静态）。
适合"每行显示自己的当前状态"，不需要再配一排 Info 行：

```csharp
.Add(new BoolSetting("enable_x", "启用 X")
{
    Description = new LazyText(() =>
        CYLibConfig.GetBool("MyMod", "enable_x") ? "当前：已生效" : "当前：已关闭"),
})
```

**RestartNote（v0.1.4）**——`RequiresRestart = true` 时可在标注旁写明"为什么需要重启"，
支持动态文本，不必挤占 `Description`：

```csharp
.Add(new BoolSetting("big_change", "大改动") { RequiresRestart = true,
      RestartNote = "该项绑定 IL 补丁，运行时改动会不一致" })
```

### 2.7 常见配方

**批量生成同构设置项**（例如 10 个结构相同的开关）——用 `foreach` 生成即可，
注意把循环变量拷进局部再进闭包（经典闭包陷阱），本地化 key 按 id 模板生成：

```csharp
var acts = new[] { "act1", "act2", "act3" };
var section = ...; // ConfigSectionBuilder
foreach (var act in acts)
{
    var a = act;                       // ★ 拷贝循环变量，避免闭包共享
    section.Add(new BoolSetting($"enable_{a}", new LazyText(() => Loc($"MYMOD.{a}.title")))
    {
        Description = new LazyText(() => Loc($"MYMOD.{a}.desc")),
        OnChanged = v => enabled[a] = v,
    });
}
```

**一个 Section 内的视觉分组**——`Header` 是普通条目，**可以重复加多次**，
插在任意两项之间就是分组标题（按幕、按主题都行）：

```csharp
.Section("进阶", s => s
    .Header("第一幕")
    .Toggle(...).Toggle(...)
    .Header("第二幕")
    .Toggle(...).Toggle(...))
```

> 暂不支持可折叠的子分组/嵌套 Section；长列表先用多 Header 分隔，
> 真撑不住再考虑平台级支持。

## 3. 文案与本地化

- **所有文本参数（`label` / `description` / 页标题等）都是 `LazyText`**：既可以直接传字符串
  字面量，也可以传 `new LazyText(() => 取文本)` 的解析器。**推荐用解析器**——模组初始化时
  游戏的本地化表可能还没加载完，推迟到界面渲染时再取文本才可靠：

  ```csharp
  // 字面量（简单，但初始化时就定死了）：
  .Toggle("enable_x", "启用 X")

  // 惰性本地化（推荐）：
  .Toggle("enable_x",
      new LazyText(() => new LocString("settings_ui", "MYMOD.enable_x.title").GetFormattedText()),
      description: new LazyText(() => new LocString("settings_ui", "MYMOD.enable_x.desc").GetFormattedText()))
  ```

- **如果你要在 CYLib 的界面文案上做文章**：CYLib 自己的界面文案都在游戏的
  `settings_ui` / `main_menu_ui` 两张表里，key 一律以 `CYLIB.` 开头，**不会**和你的 key 冲突。
  你自己的 key 请加自己的前缀（如 `MYMOD.`）。
- ⚠️ 游戏的模组本地化机制是"按文件名合并进游戏同名表"：**只能扩充已有表名**
  （`settings_ui`、`main_menu_ui`、`cards` 等），不能自创表名。文件放在
  `MyMod/localization/<语言>/settings_ui.json`（目录名必须等于模组 id）。

## 4. 配置存储

- 位置：`%APPDATA%\Godot\app_userdata\<游戏>\mod_configs\<modId>.json`
  （即游戏 `user://` 目录下的 `mod_configs/`；不确定就调 `CYLibConfig.GetFilePath(modId)`）
- 格式：

  ```json
  {
    "version": 1,
    "values": {
      "enable_x": true,
      "power": 3
    }
  }
  ```

- 特性：
  - **未知 key 保留**（你以后删了某设置项，用户文件里的旧值不会被清掉；再加回来值还在）；
  - 值类型与定义不符 → 自动回退默认值（不会崩）；
  - 文件损坏 → 自动改名为 `*.json.corrupt-<时间戳>` 备份，用默认值继续；
  - 写盘是"临时文件 + 替换"的原子写，写一半崩溃不会毁文件；
  - UI 改动 0.5 秒防抖落盘；退出游戏、关闭配置界面时强制落盘。

## 6. 自检清单（接入完成后逐项核对）

- [ ] `MyMod.json` 的 `dependencies` 里有 `{"id": "CYLib", "min_version": "v0.1.0"}`
- [ ] csproj 引用 `CYLib.dll` 且 `Private=false`（模组目录里**没有** CYLib.dll）
- [ ] `Register` 的 `modId` 与 `MyMod.json` 的 `id` **完全一致**
- [ ] 你的模组 dll 能正常编译（`CYLib.Config` 命名空间可直接 using）
- [ ] 游戏里主界面出现「模组配置」按钮（CYLib 提供；你的模组不需要做入口）
- [ ] 打开「模组配置」，左栏有你的模组，右栏设置项齐全
- [ ] 改一个值 → 关界面 → 重启游戏 → 值保持
- [ ] 点「重置为默认」→ 确认 → 值全部回到默认
- [ ] `godot.log` 里没有 `[CYLib]` 开头的报错

## 7. 常见问题

| 现象 | 原因与解法 |
| --- | --- |
| 左栏没有你的模组 | ① `Register` 没被调用（确认初始化路径）；② 该页所有设置项都是 `Hidden`；③ modId 打错了 |
| 编译找不到 `CYLib.Config` | csproj 没引用 CYLib.dll，或 HintPath 不对 |
| 运行时 `FileNotFoundException: CYLib` | 清单里没写 `dependencies`，或 CYLib 没有安装在 mods/CYLib/ |
| 界面文案显示成 `CYLIB.xxx` 原样 key | CYLib 的 .pck 没加载（检查 mods/CYLib/CYLib.pck 是否存在） |
| 你的设置项文案显示成 key | 你自己的 loc 表路径/表名不对（见 §3 本地化说明） |
| 值改了但没保存 | 只会发生在游戏被强杀/断电；正常退出与关界面都会落盘 |
