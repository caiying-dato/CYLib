# CYLib 配置平台 · 配置需求统一规划

> 状态：**规划待批准**（未动代码）
> 日期：2026-10-03
> 来源：① DAT（愈深愈肉）接入会话的 4 条建议；② 对用户其余模组的配置现状调研
> 原则：CYLib 只做「配置平台」该做的事——声明 API、统一入口、持久化、渲染；模组业务自管

---

## 一、P0：DAT 会话反馈的 4 条（CYLib API 增强）

### 1. 动态信息行（DAT 标注：最重要）

**现状**：`InfoItem.Text`（LazyText）只在建页时 `Resolve()` 一次，且不进 `_rows` 刷新链
（`NCyConfigSubmenu.AddSection`），值变化后文字不更新。DAT 只能用
`EffectPreview.RefreshLabel()` 全场景树 `FindChildren("*","Label")` 按前缀找 Label 兜底
——CYLib 内部布局/文案一变就失效，且建页时序还要 `CallDeferred` 补一帧。

**方案**：
- InfoItem / HeaderItem 的渲染登记进「动态文本刷新链」，`OnValueChanged`（任何来源）
  时重新 `Resolve()` 更新 Label——InfoItem 的 LazyText 改为**每次刷新都求值**；
- builder 增加 `Info(Func<string>)` 便捷重载（现在 lambda 不能隐式转 LazyText，必须写
  `new LazyText(() => …)`，API 体验差）；
- 受益：DAT 的场景树扫描可整体删除，`EffectPreview.InfoText()` 改成普通
  `() => …` 传给 `Info(...)` 即可。

**API 变化**（不破坏现有签名）：
```csharp
.Info(() => $"当前增幅：{HpScaling.CurrentPercent}")   // 新重载，自动随值刷新
```

### 2. 整数输入行（数字直接填）

**现状**：IntSetting 只有滑条形态；要"填数字"只能 `TextSetting + Validator` 变通，
值以**字符串**入档（DAT 的 `growth_per_mille` 就是这样），类型与语义不一致，
`GetInt` 读不回、重置/迁移易踩坑。

**方案**：
- `IntSetting` 增加 `Style = Slider | Input`（默认 Slider，不影响存量）；
- builder 增加 `IntInput(id, label, min, max, defaultValue, …)`；渲染为数字输入框
  （提交时解析→越界夹取→按 int 入档）；
- **顺带修存量问题**：`ConfigStore.GetInt/GetFloat` 做类型宽容读取（字符串能解析成
  数字就解析），DAT 档里已存的字符串值无需迁移即可被 `GetInt` 读回；
- 数字输入框同样走「校验拒绝反馈」（见第 4 条）。

### 3. 展示文字的字号/颜色/强调

**现状**：InfoItem 固定走 `CreateDescription`（小字、70% 透明度），想做"醒目大字提示"
只能像 DAT 那样拿到 Label 后自己 `AddThemeFontSizeOverride` 兜底。

**方案**：
- `InfoItem` 增加 `FontSize`（int?）与 `Color`（Color?）属性，null 用现默认；
- builder 增加 `Info(text, fontSize, color)` 重载与 `InfoTitle(text)` 变体
  （金色大字，一步到位的"醒目提示"）。

### 4. 校验拒绝反馈（输入框）

**现状**：`TextSetting.Validator` 拒绝时静默回滚，用户不知道为什么被拒。

**方案**：
- 输入框校验失败：**红框反馈**（normal/focus 样式换红边，恢复输入或提交合法值后清除）；
- `TextSetting` 增加 `OnRejected`（`Action<string>?`）回调，需要自定义提示的模组可挂
  （如弹提示条）；数字输入行共用这套反馈。

## 二、P1：其它模组的配置需求（调研汇总）

> 调研对象：全自动爬塔（AutoSTS2）、更好的进阶难度（BetterAscension）、
> 全路线求解器（GameSolver）、尖塔竞技场（SpireArena）。

### 各模组配置现状

| 模组 | 现状摘要 | 核心痛点 |
| --- | --- | --- |
| **GameSolver**（35 项设置） | 自造 `key=value` 文本 cfg（`mods/config/GameSolver.cfg`），定义散在**三处手写**（属性/TryApply/Save）；仅 5 项有临时 UI，其余手改文件；热键是裸 Godot Key 字符串（F8/F9/F10）；无本地化 | **三处同步已漂移、静默丢 2 项设置**（`AutoRoutePlanning`/`AutoCrystalSphere` 存了不写、重载丢回默认）；整文件重写毁用户注释；无重置/校验/通知 |
| **SpireArena**（6 组房间规则） | 规则仅存 `ArenaSession` 内存+网络同步，**零持久化**；房间界面有控件（OptionButton/SpinBox/CheckBox）；文案硬编码中文 | 隐私 5 开关、直连 IP/端口、HUD 状态每次重开重置；默认值硬编码改需重编译；无热键 |
| **BetterAscension**（约 12 个数值常量） | **完全无设置系统**：数值是散在 9 个补丁类的编译期常量；有 zhs/eng 本地化（进阶文案） | 玩家无法逐条启停 A11~A20、无法调数值；数值与本地化文案双份手写易失同步；IL 补丁绑定**天然需重启生效** |
| **AutoSTS2**（63 项设置） | 自研 `key=value` 文本 cfg；有 HUD 面板+弹出面板（手拼 Button 循环取值）与**热键录制面板**（仅 F1–F12/单字符，撞键标红）；无本地化、无变更通知（手动 Save+Refresh） | 同一说明写三遍（注释/cfg/UI）易漂移；用户配置与运行时状态**混存一文件**；无恢复默认/导入导出；热键不支持组合键；条件显隐手写 if |
| **DAT 愈深愈肉**（已接入 CYLib） | 已用 CYLib 注册配置页；因平台能力不足被迫兜底 | 见第一部分 4 条 |

### 诉求汇总与取舍建议

**已被 CYLib 现有能力覆盖（各模组接入即可，无需开发）**：
声明式一次注册、JSON 持久化+未知键保留、重置默认、变更通知、需重启标注、
条件显隐/置灰（父子开关）、惰性本地化文本、范围钳制、统一入口。

**需要 CYLib 新增的能力（建议开发）**：

| 优先级 | 能力 | 需求方 | 说明 |
| --- | --- | --- | --- |
| P0 | 动态信息行 / IntInput / Info 样式 / 校验反馈 | DAT | 见第一部分 4 条 |
| P0 | 类型宽容读取（GetInt/GetFloat 解析字符串数字） | DAT（存量档） | 并入 P0-2 一起做 |
| **P1** | **热键设置行（HotkeySetting）** | AutoSTS2（4 键）、GameSolver（3 键）、SpireArena | 一键捕获按键的控件：点击进入"按下按键…"捕获态、Esc 取消、Backspace 清除、**支持组合键（Ctrl/Shift/Alt+键）**、同页撞键提示；存字符串如 `"Ctrl+F8"`。**平台只存与编辑，不负责按键派发**（各模组自己挂输入） |
| P2 | 配置导入/导出 | AutoSTS2 | 页脚加"导出/导入"（把该模组 JSON 导出到文件/从文件导入），方便分享与备份 |
| P2 | 旧配置迁移（文档化模式） | GameSolver、AutoSTS2、DAT | "首次接入时把旧 cfg/旧值灌进 CYLib"的推荐写法（`Set` 循环）；顺带给 `CYLibConfig` 加一次性 `ImportOnce` 辅助 |
| P2 | 单项恢复默认（行级 ↺） | AutoSTS2 | 每行右侧小复位钮，重置该项自身 |
| P2 | 富文本说明（Rich Info） | BetterAscension | 说明文字支持游戏富文本标签（`[gold]` 等，走 MegaRichTextLabel），解决"文案带颜色强调" |

**建议不做 / 缓做**（除非你要求）：
- 跨模组热键**全局**冲突检测（v1 只做同页提示）、配置预设、按角色/按存档配置（暂无场景）；
- 「设置与运行时状态分仓」不加 API——写进接入指南当约定（CYLib 配置只存用户设置）。

## 三、范围边界（明确不做 / 缓做）

- **热键派发**：CYLib 只提供热键的录入/存储/展示，不监听全局按键、不负责触发——
  各模组继续自己挂输入（AutoSTS2 的 HotkeyPatches、GameSolver 的 F 键逻辑都保留）。
- **跨模组热键全局冲突检测**：v1 只做**同页**撞键提示；全局检测缓做。
- **配置预设、按角色/按存档配置、云同步**：暂无真实场景，不做。
- **运行时状态存储 API**：不做——写进接入指南当约定（CYLib 配置只存用户设置，
  面板位置/回放门控这类运行时状态留在模组自己手里）。
- **BetterAscension 的数值绑定 IL 补丁**：平台只管"声明+标注需重启"，运行时生效
  语义由各模组自管。

## 四、实施、兼容与验收

- **兼容**：全部为增量 API，不改现有签名；CYLib 存量配置文件不动。
- **文档**：`docs/接入指南.md` + `docs/samples/MyModConfigSample.cs` 同步更新，
  新增「旧配置迁移」章节。
- **版本**：CYLib 0.1.0 → 0.1.2；走局域网发布（`pack-release.ps1 -Publish`，按全局约定）。
- **验收**：DAT 会话删除兜底代码实测动态行；AutoSTS2/GameSolver 会话试接热键行；
  各模组会话按需接入。
